# Pilot Validation

Use to record whether a pilot project proves or disproves the SDLC route, router/reference, evidence, agent, and review assumptions.

## Template
- `.agents/templates/docs/pilot/fixture-validation-report.md`

## Pilot Tasks
- Micro/Tiny task.
- Standard behavior task.
- UI/rendered-review task.
- Weak-test/legacy simulation.
- Review-only pass.
- Optional release/handoff pass.

## What To Capture
- Predicted route and actual route.
- References loaded.
- Evidence packet used.
- Validation commands/results.
- Rendered review evidence.
- Review findings.
- Process overhead and friction.
- Router/agent/adapter issues.
- Keep/change/defer decisions.

## Output
```text
Pilot:
Tasks run:
Pass/fail/partial:
Findings:
Router changes needed:
Template changes needed:
Agent/adapter changes needed:
Next validation task:
```
