# DevEx Review

Use when reviewing CLIs, APIs, SDKs, packages, local setup, examples, package publishing, or developer tooling.

## Checks
- Time to hello world.
- Setup friction and first successful command.
- README, quickstart, and examples are accurate.
- Configuration is discoverable and has clear defaults.
- Error messages explain what failed and what to do next.
- API/CLI ergonomics match developer expectations.
- Failure modes, permissions, auth, environment variables, and local/CI differences are documented.
- Generated artifacts, package metadata, and release instructions are reviewable when relevant.

## Output
- Required DevEx fixes.
- Optional improvements.
- Documentation updates needed.
- Context/model/PRD impacts.
- Verification or example gaps.
