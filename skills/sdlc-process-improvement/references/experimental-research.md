# Experimental Research

Use this reference when an SDLC process improvement needs cross-domain inspiration, machine-native process representations, or experiment-before-process design.

## Cross-Domain Inspiration

Use outside domains as inspiration, not authority.

Possible source domains:
- manufacturing quality systems,
- lean, Kanban, and theory of constraints,
- aviation and medical checklists,
- scientific experimentation,
- statistical process control,
- operations research,
- cognitive ergonomics,
- knowledge-work systems from books and research,
- math, statistics, linear algebra, and representation design.

Evaluate cross-domain ideas with:

```text
Source domain:
Relevant principle:
Why it may apply to coding-agent SDLC:
Where the analogy breaks:
Smallest experiment:
Success signal:
Failure signal:
Adoption criteria:
Rollback criteria:
```

Prefer small experiments before durable process changes. Do not adopt an analogy when it adds ceremony, hides judgment, or fails to improve coding-agent outcomes.

## Machine-Native Process Representations

Explore whether some SDLC artifacts should be compiled into model-oriented packets instead of only human prose.

Candidate forms:
- terse structured prompts,
- keyword or trigger-word packets,
- task/context/evidence matrices,
- constraint and approval tables,
- phase-specific compressed context packets,
- statistical comparisons of prompt and packet forms,
- linear-algebra-inspired projections from large context into compact task-specific representations.

Rules:
- Preserve the original human prompt as authoritative.
- Keep human-facing handoffs, QA scripts, and final summaries readable.
- Do not silently rewrite product terms, file paths, ticket IDs, branch names, code symbols, API names, or user constraints.
- Treat compressed or machine-native representations as experimental until fixture evidence proves value.
- Compare against normal prose before promotion.
- Watch for brittle trigger-word behavior; useful compression should improve understanding, not create ritual tokens.

Experiment with:

```text
Representation:
Hypothesis:
Human-readable source:
Machine-oriented transformation:
Preserved fields:
Discarded fields:
Fixture/task:
Success signal:
Failure signal:
Human readability cost:
Agent performance result:
Adopt / revise / discard:
```
