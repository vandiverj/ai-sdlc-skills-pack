# devex-review

## Description
Review developer experience for CLIs, APIs, SDKs, packages, or developer tools.

## Checks
- Time to hello world
- Setup friction
- First successful command
- README clarity
- Error messages
- Config discoverability
- Example quality
- API ergonomics
- Failure modes

## Output
- Required DevEx fixes
- Optional improvements
- Documentation updates needed
- Context/model/PRD impacts
