
# diagram-issues

## Description
Visually map features, tasks, and dependencies before creating or coding issues.

## Purpose
Expose ordering and dependency problems before implementation begins.

## Required diagrams
- Feature dependency diagram
- Task dependency diagram
- Vertical slice map
- Issue grouping map

## Required output
- Recommended issue grouping
- First vertical slice
- Dependency order
- Risks caused by ordering
- Questions to add to `context-state.md`
