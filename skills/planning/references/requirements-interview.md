# Requirements interview

Use when an interview is requested or an unresolved decision materially affects the product.

Inspect the supplied context first. Ask the smallest useful question about the user's intended outcome, constraints, or tradeoff. Recommend an option when evidence supports one. Continue independent work while waiting.

Record decisions, scope, assumptions, and unresolved questions in the existing plan or context document when they will be reused. Stop interviewing once implementation and verification can proceed without material guessing. Use planning's PRD or application-model reference only when that artifact is needed.
