# TDD

Use when behavior can be specified with a focused failing test or regression check.

## Loop
1. Add or adjust the smallest failing test that captures the expected behavior.
2. Run the targeted test and confirm the failure is meaningful.
3. Implement the smallest fix.
4. Run the targeted test until it passes.
5. Run broader checks appropriate to the blast radius.
6. Refactor only within the approved boundary.

## Output
- Failing test added.
- Failure observed.
- Fix made.
- Passing targeted check.
- Broader verification.
